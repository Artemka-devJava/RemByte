# 🧩 Инструкция по созданию плагинов (для будущих промтов)

Этот документ нужен, чтобы быстро формулировать запросы на новые плагины и делать их совместимыми с текущей системой `RemByte CRM`.

## 1) Как сейчас работает плагин-система

- Плагин устанавливается в `Настройки -> Плагины` (только админ).
- Загружается **локальный** файл `.html`/`.htm`.
- Кнопка плагина появляется в левом меню (`🧩 <название>`).
- Плагин запускается на странице `/plugins?pluginId=...`.
- Запуск идёт в изолированном `iframe sandbox="allow-scripts allow-modals"`.

### Важно по изоляции

Плагин:
- не должен вызывать API CRM,
- не должен пытаться обращаться к `window.parent`,
- не должен ожидать доступ к DOM основной CRM.

Разрешено:
- локальная логика внутри плагина,
- `localStorage` для данных самого плагина,
- чистый HTML/CSS/JS без внешней сборки.

## 2) Минимальный контракт плагина

Плагин — это один HTML-файл.

Обязательное:
- валидный `<!DOCTYPE html>`
- `<meta charset="UTF-8">`
- UI внутри `<body>`
- JS только для собственного интерфейса

Рекомендуемое:
- адаптивная верстка
- понятный `title`
- кнопка очистки/сброса
- безопасная работа с вводом

## 3) Шаблон промта для генерации нового плагина

Используйте этот текст как основу:

```text
Сделай HTML-плагин для RemByte CRM.
Ограничения:
1) Один файл .html (без сборщиков и npm)
2) Работа только внутри sandbox iframe
3) Не обращаться к API CRM и к window.parent
4) Данные хранить только в localStorage (если нужно)
5) Интерфейс на русском

Функции плагина:
- <описать функции>
- <описать кнопки/поля>
- <описать формат данных>

Нужен готовый файл: <plugin-name>.html
```

## 4) Примеры полезных промтов

### Пример A: заметки

```text
Сделай HTML-плагин "Заметки мастера" для RemByte CRM.
Функции:
- список заметок
- добавление/редактирование/удаление
- поиск по тексту
- экспорт заметок в .txt
Ограничения: один .html, sandbox iframe, без API CRM.
```

### Пример B: таймер ремонта

```text
Сделай HTML-плагин "Таймер ремонта" для RemByte CRM.
Функции:
- запуск/пауза/сброс таймера
- сохранение истории сессий
- расчет суммарного времени за день
Ограничения: один .html, sandbox iframe, хранение в localStorage.
```

### Пример C: текстовый редактор

```text
Сделай HTML-плагин "Текстовый редактор" для RemByte CRM.
Функции:
- жирный/курсив/подчеркнутый текст
- маркированный список
- сохранить/загрузить текст локально
Ограничения: один .html, sandbox iframe, без API CRM.
```

## 5) Чеклист перед установкой плагина

- [ ] Файл открывается локально в браузере без ошибок в консоли.
- [ ] Нет попыток обращения к CRM API.
- [ ] Нет обращения к `window.parent`.
- [ ] У плагина есть понятный заголовок и базовые действия.
- [ ] Плагин не ломается при перезагрузке страницы.
