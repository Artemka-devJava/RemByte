### 2. ✅ Исправлена проблема с прыганием контента
**Статус:** Завершено

**Проблема:** При открытии модальных окон или чата/настроек контент мог прыгать влево-вправо.

**Решение:** Добавлено свойство `overflow-y: scroll` в стили `body` CSS.

```css
body {
  font-family: 'Segoe UI', system-ui, -apple-system, sans-serif;
  background: var(--c-bg);
  color: var(--c-text);
  font-size: 14px;
  line-height: 1.6;
  overflow-y: scroll;  /* ← ДОБАВЛЕНО */
}
```

**Эффект:**
- Скролбар браузера всегда видим (не появляется/исчезает)
- Контент страницы не прыгает при изменении высоты содержимого
- Это стандартная рекомендация W3C для предотвращения "layout shift"

**Затронутые файлы:**
- `src/main/resources/static/css/style.css` (строка 203)

### 3. ✅ Исправлена проблема с перемешиванием надписей в меню
**Статус:** Завершено

**Проблема:** При переходе между страницами (например Чат → Настройки) надписи в боковом меню менялись местами.

**Причина:** Flexbox layout в боковой панели был неустойчивым к изменениям размера контента.

**Решение:** Добавлены CSS свойства для стабилизации flex контейнеров:

#### В `.sidebar`:
```css
.sidebar {
  /* ... существующие свойства ... */
  flex-shrink: 0;  /* ← ДОБАВЛЕНО */
}
```
**Эффект:** Боковая панель никогда не сжимается.

#### В `.sidebar-nav`:
```css
.sidebar-nav {
  flex: 1;
  padding: 14px 10px;
  display: flex;
  flex-direction: column;
  gap: 2px;
  width: 100%;       /* ← ДОБАВЛЕНО */
  overflow: hidden;  /* ← ДОБАВЛЕНО */
}
```
**Эффект:** Содержимое меню надежно ограничено.

#### В `.nav-item`:
```css
.nav-item {
  display: flex;
  align-items: center;
  gap: 10px;
  padding: 9px 12px;
  border-radius: 8px;
  color: var(--sidebar-text);
  font-weight: 500;
  font-size: 13.5px;
  transition: all .18s;
  text-decoration: none !important;
  position: relative;
  white-space: nowrap;      /* ← ДОБАВЛЕНО */
  overflow: hidden;         /* ← ДОБАВЛЕНО */
  text-overflow: ellipsis;  /* ← ДОБАВЛЕНО */
  min-width: 0;             /* ← ДОБАВЛЕНО */
}
```
**Эффект:**
- Текст пункта меню не разбивается на две строки
- Если текст не влезает, добавляется многоточие
- Flex layout правильно сжимает содержимое

#### В `.nav-badge`:
```css
.nav-badge {
  /* ... существующие свойства ... */
  flex-shrink: 0;  /* ← ДОБАВЛЕНО */
}
```
**Эффект:** Бейджи (значки уведомлений) не сжимаются.

#### Дополнительные изменения для стабильности:
- `.sidebar-logo`: `+ overflow: hidden;`
- `.sidebar-footer`: `+ overflow: hidden;`
- `.theme-switcher`: `+ overflow: hidden;`
