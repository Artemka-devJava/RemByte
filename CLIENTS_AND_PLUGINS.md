# CLIENTS_AND_PLUGINS — клиенты и плагины FixByte CRM

## 1) Desktop-клиент (Electron)

Папка проекта:

- `desktop-client`

Основные команды:

```powershell
Set-Location "C:\JavaProject\RemByte\desktop-client"
npm install
npm run start
npm run build:win
```

Что поддерживается:

- Подключение к локальному/облачному серверу CRM
- Настройки окна запуска (ширина/высота, полноэкранный режим)
- Системный трей
- Окно настроек клиента

## 2) Mobile-клиент

Варианты:

1. Мобильный браузер (быстрее всего для эксплуатации)
2. Android WebView-клиент (проект в `mobile-client/android-webview`)

Смысл mobile-режима: доступ к той же CRM по URL, без отдельного backend.

## 3) Плагины CRM

Плагины подключаются через настройки администратора и изолированы от ядра CRM.

Текущие примеры в проекте:

- `plugin-samples/snake-game-plugin.html`
- `plugin-samples/tetris-game-plugin.html`
- `plugin-samples/text-editor-plugin.html`

### Минимальные требования к плагину

- Формат: HTML-файл
- Самодостаточный UI внутри страницы плагина
- Не должен менять структуру core-страниц CRM
- Ошибки плагина не должны ломать приложение

### Рекомендации

- Держать плагины stateless или хранить данные в выделенных API
- Использовать нейтральные стили (не глобальные сбросы)
- Делать имена и иконки плагинов понятными для пользователя

## 4) Notes/игровые плагины

Для продуктивных модулей (например, заметки, склад, конструкторы) лучше переходить от «чистого HTML-плагина» к серверному модулю с БД и API.

Игровые плагины (Snake/Tetris) подходят как демонстрация механики подключения.

## 5) Чек-лист перед установкой нового плагина

- Проверен в обычном браузере
- Нет конфликтов CSS/JS
- Проверен рендер в desktop-клиенте
- Проверено удаление/отключение плагина в настройках
- Проверено, что основной CRM-функционал не деградирует
