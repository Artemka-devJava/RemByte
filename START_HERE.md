# 🎉 ПРОЕКТ УСПЕШНО ЗАВЕРШЕН!

## 🆕 Обновления конфигурации и UI

- База данных: MariaDB (`localhost:9092`) с настройками через `.env`.
- Учетные записи: `FIXBYTE_ADMIN_*` и `FIXBYTE_OPERATOR_*` из `.env`.
- Логотип: единое изображение `/images/logo.png` на всех страницах.
- Внешний вид: переключатель темы (`system`/`light`/`dark`) с сохранением выбора.

**RemByte CRM** - Система управления сервисом по ремонту ПК и ноутбуков

### 🏗️ Архитектура

- **Backend:** Spring Boot, Spring Data JPA, Lombok
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Database:** MariaDB (через `.env`)
- **API:** RESTful, JSON

### 🎯 Компоненты

1. **JPA сущности** (6):
   - Client, Order, RepairService, Payment, OrderStatus, PaymentMethod

2. **Репозитории** (4):
   - ClientRepository, OrderRepository, RepairServiceRepository, PaymentRepository

3. **Сервисы** (5):
   - ClientService, OrderService, RepairServiceService, PaymentService, OrderStatistics

4. **REST контроллеры** (4):
   - ClientController, OrderController, RepairServiceController, WebController

5. **Веб-интерфейс** (6 страниц):
   - Главная, Панель управления, Клиенты, Заказы, Услуги, Калькулятор

6. **JavaScript модули** (6):
   - API клиент, Логика для каждого раздела

## 🎓 ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ

### Создание клиента:
```bash
curl -X POST http://localhost:9087/api/clients \
  -H "Content-Type: application/json" \
  -d '{"name":"Иван Петров","phone":"+7999123456"}'
```

### Создание заказа:
```bash
curl -X POST http://localhost:9087/api/orders \
  -H "Content-Type: application/json" \
  -d '{"client":{"id":1},"deviceDescription":"Ремонт"}'
```

### Получение статистики:
```bash
curl "http://localhost:9087/api/orders/statistics?from=2026-01-01T00:00:00&to=2026-03-31T23:59:59"
```
