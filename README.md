# FixByte CRM v1.0.3

FixByte CRM — веб-система для сервиса ремонта ПК/ноутбуков: клиенты, заказы, услуги, канбан, чат, вложения, плагины, бэкапы и desktop-клиент.

## Что осталось по документации

В проекте оставлено **только 3 файла документации**:

1. `README.md` (этот файл) — быстрый старт и обзор
2. `OPERATIONS.md` — эксплуатация, Docker, бэкапы, восстановление, диагностика
3. `CLIENTS_AND_PLUGINS.md` — desktop/mobile клиенты и система плагинов

---

## Быстрый старт (локально)

### Требования

- Java 17+
- Maven 3.9+
- MariaDB 11+ (или локально через Docker)

### Запуск

```powershell
Set-Location "C:\JavaProject\RemByte"
mvn spring-boot:run
```

После старта приложение обычно доступно по адресу:

- `http://localhost:9087`

---

## Быстрый старт (Docker)

```powershell
Set-Location "C:\JavaProject\RemByte"
docker compose up -d --build
```

Сервисы по умолчанию:

- App: `http://localhost:9087`
- MariaDB: `localhost:9092`

Подробно про контейнеры, volume и обновление: `OPERATIONS.md`.

## Основные разделы CRM

- Панель управления (дашборд)
- Клиенты
- Заказы
- Услуги и категории услуг
- Калькулятор ремонта
- Чат (встроенный модуль)
- Канбан-доски (персональные, с колонками и карточками)

## Авторизация и учётки

Логины и пароли настраиваются через переменные окружения (`.env`) и/или Spring properties.

Минимум проверьте:

- `FIXBYTE_ADMIN_USERNAME`
- `FIXBYTE_ADMIN_PASSWORD`
- `FIXBYTE_OPERATOR_USERNAME`
- `FIXBYTE_OPERATOR_PASSWORD`

Пример конфигурации и рекомендации по prod-настройкам: `OPERATIONS.md`.

---

## Вложения и хранение данных

- База данных: MariaDB
- Вложения заказов (фото/видео/файлы) хранятся в БД
- Бэкап/restore учитывает пользовательские данные и вложения

Сценарии бэкапа и восстановления: `OPERATIONS.md`.
