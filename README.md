# Инструкция по использованию RemByte CRM

## 🔄 Обновления интерфейса (27.03.2026)

- Логотип теперь берется из `src/main/resources/static/images/logo.png` и отображается на всех страницах (`index`, `login`, `dashboard`, `clients`, `orders`, `services`, `calculator`, `users`).
- Добавлен выбор внешнего вида: `Системная / Светлая / Темная`.
- Переключатель темы расположен в левом сайдбаре рабочих страниц.
- Выбранная тема сохраняется в `localStorage` (ключ `fixbyte-theme`).
- Логины/пароли для входа берутся из `.env` (`FIXBYTE_ADMIN_*`, `FIXBYTE_OPERATOR_*`), а не из hardcoded значений.

## 📋 Описание

**RemByte CRM** - это веб-приложение для управления сервисом по ремонту персональных компьютеров и ноутбуков. Система включает:

✅ **CRM для управления клиентами** - ведите базу клиентов, их контакты и историю заказов
✅ **Учет заказов** - создавайте и отслеживайте статус заказов ремонта
✅ **Калькулятор стоимости** - автоматически рассчитывайте стоимость ремонта
✅ **Управление услугами** - добавляйте свои услуги с ценами
✅ **Отслеживание платежей** - контролируйте оплату заказов
✅ **Статистика и отчеты** - анализируйте доходы и активность

## 🚀 Установка и запуск

### Требования
- Java 17 или выше
- Maven 3.8.1 или выше

### Сборка проекта

```bash
cd C:\JavaProject\RemByte
mvn clean package
```

### Запуск приложения

```bash
mvn spring-boot:run
```

Или запустить JAR файл после сборки:

```bash
java -jar target/rembyte-crm-1.0.0.jar
```

### Доступ к приложению

После запуска откройте браузер и перейдите по адресу:
```
http://localhost:9087
```

## 🎯 Основные функции

### Управление клиентами
```
Поле              Описание
ФИО/Название     Имя или название организации клиента
Телефон          Контактный номер телефона
Email            Электронная почта
Адрес            Адрес клиента
Заметки          Дополнительная информация
```

### Управление заказами
```
Статусы:
- Новый (NEW) - Только создан
- В работе (IN_PROGRESS) - Выполняется ремонт
- Ожидание деталей (WAITING_FOR_PARTS) - Ждем комплектующие
- Готов (READY) - Готов к выдаче
- Завершен (COMPLETED) - Выдан клиенту
- Отменен (CANCELLED) - Заказ отменен
```

### Категории услуг
- **BGA** - Замена микросхем BGA (видеокарта, чипсет)
- **Экран** - Замена дисплеев и матриц
- **Батарея** - Замена аккумуляторов
- **Материнская плата** - Замена МП
- **Обслуживание** - Чистка, смена термопасты
- **Хранилище** - Замена HDD на SSD
- **Данные** - Восстановление данных
- **Программное обеспечение** - Переустановка ОС

## 💡 Примеры использования

### Пример 1: Создание новой услуги (замена BGA)
1. Перейдите в раздел "Услуги"
2. Нажмите "+ Добавить новую услугу"
3. Заполните форму:
   - Название: "Замена BGA микросхемы"
   - Описание: "Замена вышедшей из строя видеокарты или чипсета"
   - Категория: "BGA"
   - Цена: "3500"
4. Нажмите "Добавить услугу"

### Пример 2: Создание нового заказа
1. Перейдите в раздел "Заказы"
2. Нажмите "+ Создать новый заказ"
3. Выберите клиента из списка
4. Опишите проблему (например: "Ноутбук не включается")
5. Выберите нужные услуги (отметьте чекбоксы)
6. Проверьте итоговую стоимость
7. Нажмите "Создать заказ"

### Пример 3: Использование калькулятора
1. Перейдите в раздел "Калькулятор"
2. Выберите нужные услуги
3. Отметьте дополнительные опции (если нужны):
   - Диагностика (+500₽)
   - Срочность (+20%)
   - Гарантия на работу (+15%)
4. Введите скидку в процентах (если есть)
5. Смотрите итоговую стоимость

## 🔐 Безопасность

- Все данные хранятся в MariaDB
- API защищена базовой валидацией
- Рекомендуется использовать HTTPS в продакшене

## 💾 База данных

Используется MariaDB. Параметры подключения и учетные данные берутся из `.env`.

Минимально необходимые переменные:

```properties
SPRING_PROFILES_ACTIVE=dev
MARIADB_URL=jdbc:mariadb://localhost:9092/rembyte?createDatabaseIfNotExist=true&useUnicode=true&characterEncoding=UTF-8
MARIADB_USERNAME=root
MARIADB_PASSWORD=***
FIXBYTE_ADMIN_USERNAME=admin
FIXBYTE_ADMIN_PASSWORD=***
FIXBYTE_OPERATOR_USERNAME=operator
FIXBYTE_OPERATOR_PASSWORD=***
```

## 🐛 Отладка

### Проверка переменных окружения

Убедитесь, что `.env` заполнен и загружается приложением (`spring.config.import=optional:file:.env[.properties]`).

### Логирование
Установите уровень логирования в `application.properties`:
```properties
logging.level.com.rembyte=DEBUG
```
