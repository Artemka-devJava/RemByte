## 📋 Описание

**RemByte CRM** - это веб-приложение для управления сервисом по ремонту персональных компьютеров и ноутбуков. Система включает:

✅ **CRM для управления клиентами** - ведите базу клиентов, их контакты и историю заказов
✅ **Учет заказов** - создавайте и отслеживайте статус заказов ремонта
✅ **Калькулятор стоимости** - автоматически рассчитывайте стоимость ремонта
✅ **Управление услугами** - добавляйте свои услуги с ценами
✅ **Отслеживание платежей** - контролируйте оплату заказов
✅ **Статистика и отчеты** - анализируйте доходы и активность

## 🚀 Установка и запуск

### Требования
- Java 17 или выше
- Maven 3.8.1 или выше

### Сборка проекта

```bash
cd C:\JavaProject\RemByte
mvn clean package
```

### Запуск приложения

```bash
mvn spring-boot:run
```

Запуск в Docker:

```bash
docker compose up -d --build
```

Или запустить JAR файл после сборки:

```bash
java -jar target/rembyte-crm-1.0.3.jar
```

### Доступ к приложению

После запуска откройте браузер и перейдите по адресу:
```
http://localhost:9087
```

## 🧱 Архитектура шаблонов

Для единообразия интерфейса общие части вынесены в `src/main/resources/templates/fragments/`:

- `head-common.html` — единый `<head>` (title, favicon, css)
- `sidebar-nav.html` — меню + авто-подсветка active
- `sidebar-shell.html` — каркас боковой панели
- `theme-switcher.html` — переключатель темы
- `sidebar-user.html` — профиль/выход
- `common-scripts.html` — общие скрипты (`theme.js`, `plugin-host.js`) и toast-контейнер

Это снижает риск рассинхронизации между страницами (`/dashboard`, `/clients`, `/orders`, `/chat`, `/kanban`, и др.) и упрощает поддержку.

- `🧾` Настройка чека/квитанции (реквизиты, видимость полей)

- `🗄️` Резервное копирование и восстановление БД
- `🧩` Управление плагинами (в т.ч. включение/отключение встроенного плагина `Заметки`)

### 8. 🧩 Плагин заметок (встроенный)
- Страница: `/notes` (пункт в левом меню `🧩 Заметки`)
- Данные хранятся в MariaDB (таблицы `note_folders`, `note_items`)
- Возможности:
  - создание папок
  - создание/редактирование заметок в папках
  - режим `Markdown редактирование`
  - режим `Markdown превью`
  - скачивание заметки в `.txt`

Включение/отключение плагина заметок:
- `Настройки -> Плагины -> Встроенные плагины -> Плагин «Заметки»`
- при отключении скрывается пункт меню, `/notes` и API заметок блокируются

### 9. 💬 Модуль онлайн-чата (встроенный)
- Страница оператора: `/chat`
- Публичный iframe-виджет: `/widget/chat/frame`
- Данные хранятся в MariaDB: `chat_widget_sites`, `chat_conversations`, `chat_messages`
- Возможности:
  - прием сообщений с внешнего сайта в CRM
  - ответы оператора из CRM
  - счетчик непрочитанных диалогов в левом меню
  - ограничение встраивания по списку разрешенных `origin`

### 10. 🗂️ Канбан (встроенный)
- Страница: `/kanban`
- Данные хранятся в MariaDB: `kanban_boards`, `kanban_columns`, `kanban_cards`, `kanban_card_attachments`
- Возможности:
  - несколько досок на пользователя (доски изолированы по владельцу)
  - создание и переименование досок
  - переименование колонок (`К выполнению`, `В работе`, и т.д.)
  - drag-and-drop перемещение карточек между колонками
  - вложения в карточках: изображения и текстовые файлы (`.txt`, `.md`, `.csv`, `.log`)
  - первое изображение карточки показывается как превью прямо на карточке
- Ограничения по умолчанию:
  - до `10` файлов за один запрос
  - изображение до `15MB`
  - текстовый файл до `20MB`

## 🎯 Основные функции

### Управление клиентами
```
Поле              Описание
ФИО/Название     Имя или название организации клиента
Телефон          Контактный номер телефона
Email            Электронная почта
Адрес            Адрес клиента
Заметки          Дополнительная информация
```

### Управление заказами
```
Статусы:
- Новый (NEW) - Только создан
- В работе (IN_PROGRESS) - Выполняется ремонт
- Ожидание деталей (WAITING_FOR_PARTS) - Ждем комплектующие
- Готов (READY) - Готов к выдаче
- Завершен (COMPLETED) - Заказ завершен
- Отменен (CANCELLED) - Заказ отменен
```

Дополнительно для статуса `COMPLETED`:
- Доступен печатный чек/квитанция
- PDF-чек можно прикрепить к заказу как вложение

### Категории услуг
- **BGA** - Замена микросхем BGA (видеокарта, чипсет)
- **Экран** - Замена дисплеев и матриц
- **Батарея** - Замена аккумуляторов
- **Материнская плата** - Замена МП
- **Обслуживание** - Чистка, смена термопасты
- **Хранилище** - Замена HDD на SSD
- **Данные** - Восстановление данных
- **Программное обеспечение** - Переустановка ОС

## 💡 Примеры использования

### Пример 1: Создание новой услуги (замена BGA)
1. Перейдите в раздел "Услуги"
2. Нажмите "+ Добавить новую услугу"
3. Заполните форму:
   - Название: "Замена BGA микросхемы"
   - Описание: "Замена вышедшей из строя видеокарты или чипсета"
   - Категория: "BGA"
   - Цена: "3500"
4. Нажмите "Добавить услугу"

### Пример 2: Создание нового заказа
1. Перейдите в раздел "Заказы"
2. Нажмите "+ Создать новый заказ"
3. Выберите клиента из списка
4. Опишите проблему (например: "Ноутбук не включается")
5. Раскройте нужные группы услуг и отметьте чекбоксы
6. (Опционально) Добавьте новую услугу через блок "Быстро добавить новую услугу"
7. Проверьте итоговую стоимость
8. Нажмите "Создать заказ"

### Пример 3: Использование калькулятора
1. Перейдите в раздел "Калькулятор"
2. Выберите нужные услуги
3. Отметьте дополнительные опции (если нужны):
   - Диагностика (+500₽)
   - Срочность (+20%)
   - Гарантия на работу (+15%)
4. Введите скидку в процентах (если есть)
5. Смотрите итоговую стоимость

## 🔐 Безопасность

- Все данные хранятся в MariaDB
- Вложения заказов (фото/видео/документы/PDF-чек) также хранятся в MariaDB (таблица `order_attachments`, тип `LONGBLOB`)
- В Docker для вложений не требуется отдельный volume `uploads`: достаточно volume БД
- API защищена базовой валидацией
- Рекомендуется использовать HTTPS в продакшене

## 💾 База данных

Используется MariaDB. Параметры подключения и учетные данные берутся из `.env`.

При старте приложения выполняется миграция legacy-вложений из `uploads/orders/**` в таблицу `order_attachments` (идемпотентно, без дублей).
Управление через env:

```properties
FIXBYTE_UPLOAD_MIGRATION_ENABLED=true
FIXBYTE_UPLOAD_MIGRATION_DELETE_LEGACY=false
```

Также для администратора доступны:
- `GET /admin/backup?mode=full` — скачать полный бэкап `.zip` (дамп БД + legacy `uploads/**`, если есть)
- `GET /admin/backup?mode=db` — скачать бэкап только БД `.zip`
- `POST /admin/restore` — восстановить из `.zip` или legacy `.sql` (полная замена данных)

Минимально необходимые переменные:

```properties
SPRING_PROFILES_ACTIVE=dev
MARIADB_URL=jdbc:mariadb://localhost:9092/rembyte?createDatabaseIfNotExist=true&useUnicode=true&characterEncoding=UTF-8
MARIADB_USERNAME=root
MARIADB_PASSWORD=***
FIXBYTE_ADMIN_USERNAME=admin
FIXBYTE_ADMIN_PASSWORD=***
FIXBYTE_OPERATOR_USERNAME=operator
FIXBYTE_OPERATOR_PASSWORD=***
```

## 🖥️ Десктопный клиент для Windows

Помимо браузера, CRM можно открывать как нативное Windows-приложение.

**Расположение:** `desktop-client/`  
**Технология:** Electron 35.7.5  
**Требования:** Windows 10/11 x64, Node.js 18+

### Быстрый старт клиента

```powershell
cd desktop-client
npm install
npm start              # запустить в dev-режиме
```

### Сборка .exe

```powershell
# Если иконка ещё не сгенерирована:
node make-icon.js

# Собрать установщик + portable:
npm run build:win
```

Готовые файлы появятся в `desktop-client/dist/`:
```
FixByte CRM Setup 1.0.3.exe      ← NSIS-установщик
FixByte-CRM-Portable-1.0.3.exe   ← Portable
```
