# FixByte CRM — Android

Нативное приложение для сотрудников сервиса: список клиентов, карточка клиента,
и **загрузка фотографий проблем / устройств прямо в базу CRM** (камера или галерея).

## Что делает

| Экран | Возможности |
|---|---|
| **Вход** | адрес сервера + логин/пароль. Сессия сохраняется между запусками. |
| **Клиенты** | список всех клиентов, поиск по имени/телефону/email, pull-to-refresh, **кнопка «＋ Клиент»** (имя + телефон + тип; при дубле телефона предлагает открыть существующего), выход из меню. |
| **Карточка клиента** | контакты, тип, метки, заметка; сводка (заказов / оборот / долг); кнопки «Позвонить» и «Написать» (Telegram/WhatsApp/Email по предпочтительному каналу); **сетка фото** с добавлением (камера/галерея, с подписью), просмотром на весь экран, **отправкой в соцсети/мессенджеры** (системный «Поделиться») и удалением. |

Фото уходят на `POST /api/clients/{id}/photos` и хранятся в БД CRM
(таблица `client_photos`). Крупные снимки перед отправкой ужимаются до ~1600px.
«Поделиться» скачивает фото из CRM и отдаёт его в системный chooser
(`ACTION_SEND image/jpeg`) — WhatsApp, Telegram, VK, почта и т.д.

## Сборка

Нужен **Android Studio** (Giraffe+) или Android SDK + JDK 17.

1. Открыть папку `mobile-client/android` в Android Studio → Gradle Sync
   (студия сама скачает нужный Gradle 8.5 и зависимости).
2. Запустить на эмуляторе или устройстве (`Run 'app'`).
3. Сборка APK из консоли (после того как Studio один раз сгенерирует wrapper):
   ```
   ./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
   ./gradlew assembleRelease      # без подписи; для стора настроить signingConfig
   ```

> В репозитории нет `gradle-wrapper.jar` и скриптов `gradlew` (бинарник).
> Android Studio создаёт их при первом открытии, либо выполните
> `gradle wrapper --gradle-version 8.5` при наличии установленного Gradle.

## Адрес сервера

Поле «Адрес сервера» на экране входа:

- **Эмулятор** → `http://10.0.2.2:9087` (это `localhost` хост-машины). Значение по умолчанию.
- **Телефон в той же сети** → `http://<IP-компьютера>:9087` (например `http://192.168.1.50:9087`).
- **Продакшн** → `https://crm.fix-byte.ru`.

HTTP для локальной сети разрешён (`network_security_config.xml`).

## Требования к серверу

Нужен эндпоинт входа `POST /api/auth/login` (добавлен в CRM вместе с этим
приложением). Аутентификация — по cookie сессии, тем же клиентом ходит и
загрузчик картинок (иначе `.../photos/{id}/raw` вернёт 401).

## Стек

Kotlin, Views + ViewBinding, OkHttp (cookie сессии в SharedPreferences),
Coil (картинки через тот же OkHttp), Material 3. Без Compose и кодогенерации —
проект максимально простой для правок.
