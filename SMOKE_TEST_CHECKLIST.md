# Smoke Test Checklist

## Перед началом
- [ ] Приложение доступно по `http://localhost:9087`
- [ ] База данных MariaDB доступна
- [ ] Логи старта без критических ошибок

## 1. Авторизация и роли
- [ ] Вход под `ADMIN`
- [ ] Вход под `OPERATOR`
- [ ] Проверка, что админ-разделы недоступны оператору

## 2. Заказы и статусы
- [ ] Создать новый заказ
- [ ] Изменить статус заказа
- [ ] При статусе `COMPLETED` доступна кнопка печати чека

## 3. Вложения
- [ ] Прикрепить фото
- [ ] Прикрепить видео
- [ ] Прикрепить текстовый/документный файл
- [ ] Открыть вложение по ссылке
- [ ] Удалить вложение
- [ ] Убедиться, что вложение не открывается после удаления

## 4. Админ-настройки
- [ ] Открыть `/admin`
- [ ] Настройки чека сохраняются
- [ ] Управление пользователями работает (создание/роль/активация)
- [ ] Работает backup (`/admin/backup`)
- [ ] Работает restore (`/admin/restore`) в тестовой среде

## 5. Плагины
- [ ] Загрузить локальный HTML-плагин
- [ ] Появилась кнопка плагина в левом меню
- [ ] Плагин открывается и работает
- [ ] Основная CRM не ломается при включенном плагине

## 6. Темы и UI
- [ ] Переключить тему (system/light/dark)
- [ ] Проверить тему `fixbyte`
- [ ] Логотип отображается на всех страницах

## 7. Docker-проверка (если используется)
- [ ] `docker compose ps` показывает `app` и `db` как `running`
- [ ] После перезапуска контейнеров вложения и данные заказов доступны

## Команды для быстрой проверки (опционально)
```powershell
Set-Location "C:\JavaProject\RemByte"
docker compose ps
docker compose logs --tail 200 app
mvn test -DskipTests=false
```
