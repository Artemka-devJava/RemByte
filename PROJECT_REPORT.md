## 🗄️ База данных

**MariaDB (постоянное хранение данных)**
- Подключение через profile-based конфигурацию (`dev`/`prod`)
- Параметры подключения и секреты в `.env`
- Автоматическое обновление схемы в `dev` (`ddl-auto=update`)
- Режим проверки схемы в `prod` (`ddl-auto=validate`)

**Таблицы:**
- `clients` - информация о клиентах
- `services` - каталог услуг
- `orders` - заказы
- `payments` - платежи
- `order_services` - связь заказов и услуг (many-to-many)

## 🎓 Примеры использования

### Создание клиента через API:
```bash
curl -X POST http://localhost:9087/api/clients \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Иван Петров",
    "phone": "+7 999 123 45 67",
    "email": "ivan@example.com"
  }'
```

### Создание заказа через API:
```bash
curl -X POST http://localhost:9087/api/orders \
  -H "Content-Type: application/json" \
  -d '{
    "client": {"id": 1},
    "deviceDescription": "Ноутбук не включается",
    "services": [{"id": 1}]
  }'
```

### Получение статистики:
```bash
curl http://localhost:9087/api/orders/statistics?from=2026-01-01T00:00:00&to=2026-03-31T23:59:59
```

## 🔄 Жизненный цикл заказа

```
1. Новый заказ (NEW)
   ↓
2. В работе (IN_PROGRESS)
   ↓
3. Ожидание деталей (WAITING_FOR_PARTS) [опционально]
   ↓
4. Готов к выдаче (READY)
   ↓
5. Завершен (COMPLETED)
   
[Альтернатива: Отменен (CANCELLED)]
```
